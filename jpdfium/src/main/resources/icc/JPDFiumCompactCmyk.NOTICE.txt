JPDFiumCompactCmyk.icc

A generated, generic 4-component CMYK output profile for systems that have no
printing-condition ICC profile installed. It is a generic
fallback, not a certified characterization of a real press, ink, or paper.
Use a vendor or standard profile (for example FOGRA, SWOP, or JapanColor) when
the output intent must identify a specific printing condition.

The profile is generated from an sRGB model by native/tools/gen_compact_icc.c
with a higher-resolution 11-point B2A grid and a consistent GCR table. It defines only the
perceptual A2B0/B2A0 tables; other rendering intents fall back to perceptual. JPDFium releases this file under the same MIT terms as the
rest of the project.
