JPDFiumCompactCmyk.icc

A generated, generic 4-component CMYK output profile for systems that have no
printing-condition ICC profile installed. It is derived from the CC0
CGATS001Compat-v2-micro.icc profile by Clinton Ingram (saucecontrol):
https://github.com/saucecontrol/Compact-ICC-Profiles It is a generic
fallback, not a certified characterization of a real press, ink, or paper.
Use a vendor or standard profile (for example FOGRA, SWOP, or JapanColor) when
the output intent must identify a specific printing condition.

The profile is generated by native/tools/gen_compact_icc.c from the CC0
CGATS001Compat source: the A2B table reuses its CMYK->Lab measurements and the
B2A table is a sampled inverse on an 11-point Lab grid. It defines only the
perceptual A2B0/B2A0 tables; other rendering intents fall back to perceptual. JPDFium releases this file under the same MIT terms as the
rest of the project.
