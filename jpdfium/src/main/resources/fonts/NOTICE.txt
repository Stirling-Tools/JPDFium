The .xz files are font files compressed with XZ using a 16 MiB dictionary so
the runtime can decode them with a bounded memory limit. Noto Sans SC is a
wght=400 static instance of Google Fonts' variable Noto Sans SC face.
manifest.tsv maps each resource to its PostScript name; PdfFontEmbedder reads it
to build the deterministic fallback index without decompressing every face.
