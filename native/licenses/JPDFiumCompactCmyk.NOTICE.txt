JPDFiumCompactCmyk.icc

A generated, generic 4-component CMYK output profile for systems that have no
printing-condition ICC profile installed. Its A2B data comes from the CC0 CGATS001Compat-v2-micro.icc profile by
Clinton Ingram (saucecontrol):
https://github.com/saucecontrol/Compact-ICC-Profiles

Its B2A table is calibrated against a synthetic 17-level RGB->CMYK response
table (native/tools/gs_cmyk_calibration.bin) produced by Ghostscript's default
CMYK conversion. The calibration data contains only numeric colour responses,
not Ghostscript code or any Ghostscript ICC profile.

It is a generic fallback, not a certified characterization of a real press,
ink, or paper.
Use a vendor or standard profile (for example FOGRA, SWOP, or JapanColor) when
the output intent must identify a specific printing condition.

The profile is generated by native/tools/gen_compact_icc.c: A2B reuses the
CGATS CMYK->Lab measurements, and the B2A table is a 33-point Lab grid whose
values come from the RGB calibration table. It defines perceptual and colorimetric A2B/B2A tables plus a gamut tag;
other rendering intents fall back to perceptual.
