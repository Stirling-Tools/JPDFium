# Java downcall inventory

Generated by `native/tools/downcall_inventory.py`; do not edit by hand.

465 distinct native symbols across 39 Java classes. 426 reach PDFium; 421 are bound through a native `jpdf_guard_*` shim; 19 already have a safe `jpdf_*` replacement.

`PDFium` is name-based: bridge wrappers around other libraries count as `no`. Confirm each entry against its C++ body when migrating it. `Domain` is `guarded` when the Java binding reaches it through its guard shim, `unguarded` for PDFium-free entry points, and `unadmitted` when a PDFium-touching symbol has no guard shim.
